# Map Monsters — plate sources

Working files behind `experiments/map-monsters/`. The published page uses WebP copies of the renders here; this folder is not part of the site build.

## Layout

| Path | What | In Git |
|---|---|---|
| `build/` | Scripts and `crops.json` (crop boxes per cell) | yes |
| `sources/` | Downloaded public-domain scans, each with a `.json` sidecar (Commons page, licence) | no, 181 MB |

## Rebuild the "from the sources" plates

```bash
cd experiments-source/map-monsters/build
python3 -I crop.py     # sources/ -> crops/
python3 -I plate.py    # Plate VIII -> renders/
python3 -I plates.py   # Plates IX and X -> renders/
```

Needs Pillow. Run with `-I` because the scans are untrusted downloads. Then export WebP copies into `experiments/map-monsters/img/` (`<plate>-sources.webp` at 2400 px, `<plate>-sources-1200.webp` at 1200 px).

To change a crop, edit `build/crops.json`; `grid.py <source> <out> [x0 y0 x1 y1] [step]` draws a coordinate grid over a scan in `build/views/` to pick boxes. Captions live in `plate.py` (Plate VIII) and `plates.py` (IX, X).

## Fetching scans

`fetch.py <out_name> <width or 0> "File:<Commons title>"` downloads into `sources/` with a provenance sidecar. Wikimedia rate-limits full-size downloads and odd thumbnail widths: use 0 sparingly, and prefer standard widths (960, 1280, 1920, 3840). Internet Archive and BHL pages came via `pages.py`. If `sources/` is lost, the sidecars' Commons links and `sources/manifest-plate-viii.json` (also mirrored in the page's source list) say where every scan came from.
